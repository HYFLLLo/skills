# 学习计划与学习科学方法

## 制定学习计划的要点

1. **评估输入**：根据全书章节数、每章篇幅、用户可投入时间（每天几小时），估算总学习周期。
2. **合理拆分**：把书拆成阶段，每阶段聚焦一个主题模块，避免碎片化。
3. **说明阶段间的联系**：计划里要写清每个阶段为下一个阶段提供了什么基础（为什么这个顺序），让用户理解学习路径的逻辑，而不是拿到一张冷冰冰的进度表。
4. **写入 state.md**：计划确认后写入 `~/.book-tutor/books/<book-slug>/state.md`，包含阶段划分、每章预计日期、复习节点。
5. **可调整**：计划是参考，根据用户实际进度灵活调整，不要僵化。

## 学习者画像（profile.md）

首次使用本 skill 时，在 `~/.book-tutor/profile.md` 中建立学习者画像，跨书复用：
- 学习目标（通读、备考、解决特定问题）
- 学习节奏偏好（每天可投入时间、喜欢的讲解深度）
- 强项与弱项（擅长的领域、反复出错的概念）
- 偏好的讲解风格（偏直觉还是偏形式化、是否需要大量例子）
- **已掌握领域 / 不熟悉领域**：用于挑选类比的素材（见 `explaining-well.md` §1.2）
- **是否要求"更易懂/更连贯/更详细"**：若用户明确表示内容难懂，把讲解厚度与类比密度调高，并在每次讲解前对照 `explaining-well.md` 的检查清单

每次学习后如有新发现（如某个概念反复出错），更新 profile.md。

## 学习科学方法（用于指导用户）

### 间隔重复（Spaced Repetition）

复习间隔：**D+1、D+3、D+7、D+14、D+30**（学完当天为 D+0）。

具体执行机制见 `references/review-schedule.md`。核心流程：
- 每章学完后，在 `state.md` 中记录该章的复习日期列表。
- 每次学习开始时，先检查 `state.md` 中是否有到期复习任务，优先执行。
- 复习形式：综合测验 + 苏格拉底提问，覆盖该章重点与难点。

### 主动回忆（Active Recall）

比被动重读更有效。通过提问、测验让用户主动回忆，而不是反复看。这就是本 skill 采用"讲解 → 提问 → 测验"的原因。

### 费曼技巧（Feynman Technique）

让用户用自己的话复述概念，讲给"别人"听。可让用户尝试向 AI 解释某个概念，AI 扮演"完全不懂的人"来追问，迫使用户讲清楚。建议：
- 每章测验里至少安排一道"用你自己的话向外行解释 X"的题
- 复习时先让用户复述该章「一句话主线」，再出题

### 交错练习（Interleaving）

混合练习不同类型的问题，而不是连续做同类题。在综合测验中混合各章内容，避免用户形成"按题型猜答案"的习惯。

### 精细加工（Elaboration）

不要孤立地记概念，而是把新概念与已知概念建立联系（"它和上一章的 X 是什么关系？"）。这正是本 skill 要求「五连映射」与跨章回指的理论依据——联系越多，提取路径越多，记得越牢。

### 双重编码（Dual Coding）

文字之外尽量配结构化视觉：ASCII 图、表格、概念地图。图像与文字双通道编码，理解与记忆都更好。

## 学习动力维护

- 每完成一章，明确肯定用户的进度，更新 `state.md` 中的进度条。
- 当用户遇到困难时，鼓励并拆解问题，降低挫败感。
- 适时回顾已学成就，对照 profile.md 中的初始目标，增强信心。
- 如果用户反馈"看不懂/太跳/跟不上"，不辩解，直接调整讲解厚度并对照 `explaining-well.md` 重讲。
