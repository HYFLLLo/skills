# 复习日程（间隔重复机制）

本文件规定如何用**间隔重复（Spaced Repetition）**安排复习。制定计划、会话开始发现到期项、用户要求复习时读取。

## 间隔序列

采用固定间隔序列：**D+1 → D+3 → D+7 → D+14 → D+30**（D 为首次学习日）。

- 每学完一章，就在 `state.md` 的复习日程里登记该章，下次复习设为 **首次学习日 +1 天**
- 每次复习后，按表现决定进入下一阶段还是回退

| 阶段 | 间隔 | 含义 |
|------|------|------|
| D+1 | 1 天 | 第一次巩固，防快速遗忘 |
| D+3 | 3 天 | 第二次巩固 |
| D+7 | 7 天 | 转为中期记忆 |
| D+14 | 14 天 | 转为长期记忆 |
| D+30 | 30 天 | 基本固化 |

## 日期计算

- 所有日期以**当天日期**为基准（用命令获取，别凭记忆猜）。Windows PowerShell：`Get-Date -Format "yyyy-MM-dd"`；macOS/Linux：`date +%F`。
- 到期的判定：`下次复习 ≤ 今天` 即视为到期。
- 计算后写回 `state.md`。

> 不要凭记忆猜日期，每次都用命令取当天日期再计算。

## 复习日程表格式（写在 `state.md`）

```markdown
## 复习日程
| 章节 | 首次学习日 | 下次复习 | 阶段 | 上次表现 |
|------|-----------|----------|------|----------|
| 1 | 2026-09-20 | 2026-09-21 | D+1 | 待复习 |
| 2 | 2026-09-22 | 2026-09-25 | D+3 | 良好 |
```

## 复习会话流程

当用户要复习、或会话开始发现"下次复习 ≤ 今天"的条目：

1. **列出到期章节**，向用户确认要复习哪些
2. **先复述后提问**：先让用户用自己的话复述到期章节的「一句话主线」（费曼技巧），暴露记忆缺口
3. **交错混合出题**（Interleaving）：不要按章节顺序连续考，混合多个到期章节的内容，题型混合概念/应用
4. **优先考弱项**：从 `profile.md` 的"弱项与易错概念"里挑题，重点覆盖
5. **先答后批**：让用户先作答，再逐题批改讲解
6. **评估表现并调整间隔**（见下）
7. **更新 `state.md`**：填写"上次表现"、推进"阶段"、计算新的"下次复习"

## 表现评估与间隔调整

| 表现 | 处理 |
|------|------|
| 全部答对、理解透彻 | 进入下一阶段（间隔拉长） |
| 大部分答对、个别模糊 | 停留当前阶段，重复一次 |
| 明显答错、概念混淆 | **回退一阶段**（间隔缩短），并回炉讲解该知识点 |
| 完全不会 | 回到 D+1，重新讲解，记入 `profile.md` 弱项 |

> 原则：**答得好就拉长，答得差就缩短**。间隔要跟着掌握度走，不要机械推进。

## 「回炉讲解」怎么做

复习中发现某概念忘了/混淆了，不要只给答案了事，而要用 `explaining-well.md` 的方法**重新讲一遍**：

- 换一个类比或换个角度重讲（第一次用的类比显然没记住，就换一个）
- 补上当初可能漏掉的「动机」和「反例」
- 讲完立刻用一个新例子让用户复述，确认真的接上了

## 与学习者画像联动

- 复习中暴露的新弱项 → 追加到 `profile.md` 的"弱项与易错概念"表
- 反复答错的概念 → 在下次新章讲解时主动联系、类比强化
- 某弱项连续两次复习都答对 → 从弱项表移到"已巩固"（保留历史，不要直接删除）

## 提醒时机

- **会话开始**：若发现到期项，主动提醒："有 K 个章节到了复习时间，要不要先复习？"
- **每次学习结束**：在进度摘要里给出下次复习提醒
- **不要**在用户正专注学新章时强行打断去复习，除非用户同意

## 学习科学依据

- **间隔重复**：在遗忘临界点复习，效率远高于集中突击
- **主动回忆**（Active Recall）：复习用"提问+作答"，不是重读笔记
- **交错练习**（Interleaving）：混合不同章节/题型，提升迁移能力
- **费曼技巧**：可让用户用自己的话复述某章核心，AI 扮演"完全不懂的人"追问
